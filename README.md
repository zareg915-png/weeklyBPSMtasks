# BPSM weekly practices

week 1 day 2  tried different commands from generated questions.
week 2  day 1  unix intro 1 of 2 tried answering 5 questions about example_people_data.tsv 

Topics practised:

## Computing basics
- Hardware, software and source code
- Operating systems, Linux distributions and LTS
- Terminal, command line and shells
- Bash, zsh and SSH

## Directories and files
- Absolute and relative paths
- Home (~), current (.) and parent (..) directories
- Navigation: pwd, cd, ls and tree
- Creating files and directories: touch and mkdir
- Copying, moving and deleting: cp, mv, rm and rmdir

## Help and viewing files
- Getting help: man, help and --help
- Viewing files: cat, head and tail
- Counting lines, words and characters with wc

## Processing text and data
- Tab-separated files, headers, rows and fields
- Excluding blank lines and incomplete records
- Pipes (|), output redirection (>) and appending (>>)
- Pattern matching with grep and regular expressions
- Sorting with sort and counting repeats with uniq -c
- Selecting columns with cut
- Numeric, reverse and multiple-key sorting

## awk
- BEGIN, FS and tab separators
- NF, $0 and numbered fields such as $1 and $7
- Conditions and comparisons
- AND (&&) and OR (||)
- Printing matching rows or selected fields
- Replacing text with sub
- Passing Bash variables into awk with -v

## Bash scripting
- Shebangs and comments
- Displaying messages with echo
- Variables and command substitution: $(...)
- Single and double quotes
- Counters and conditions
- IFS and reading files line by line
- while loops, for loops and if statements

## People dataset exercises
- Counting valid people
- Counting people by birth year
- Finding people called Jan or jan
- Finding the most common country of birth
- Counting people from that country born in 1976 or earlier
- Selecting people with .edu email addresses
- Sorting names in reverse order within each country
- Exploring grouping people using Bash loops

## Vim
- Opening and editing files
- Saving with :w
- Saving and quitting with :wq
- Understanding swap files and recovery
- Handling unsaved changes

## Git and GitHub
- Initialising repositories and using .gitignore
- Checking changes with git status
- Staging changes with git add
- Recording changes with git commit
- Setting up remotes and pushing to GitHub
- Understanding branches
- Moving tracked files with git mv
- Organising work into weekly directories
- Maintaining a README in the repository root
